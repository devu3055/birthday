# Heet Birthday Surprise ♡

A romantic, animated birthday website made for Heet by Devanshi.

## Files
- index.html — website structure/content
- style.css — design, responsive layout, animations
- script.js — timeline, interactions, hearts, modal and music

## How to use
1. Keep all three files in the same folder.
2. Open `index.html` in Chrome/Edge.
3. Optional: add your favorite song as `our-song.mp3` in the same folder. The music button will then play/pause it.
4. To personalize further, edit the letter and timeline in `index.html` / `script.js`.

## Easy personalization ideas
- Add your photos as a new gallery section.
- Replace the background music with “your song”.
- Add a final proposal-style question such as “Will you keep choosing me?”
- Deploy free using GitHub Pages, Netlify, or Vercel.
